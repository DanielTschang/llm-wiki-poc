# Store the wiki as an OKF v0.2 Knowledge Bundle

`wiki/` is an [OKF v0.2](../../doc/okf-spec.md) Knowledge Bundle: every file except the reserved `index.md`/`log.md` must be a Concept document with YAML frontmatter carrying at least a `type`, and `log.md` must follow OKF's newest-first, date-grouped §9 format rather than the simple append-only chronological log originally sketched for this POC. `write_file` enforces this mechanically — it rejects a write missing valid frontmatter or a `type`, and force-overwrites the `generated: {by, at}` field on every write so page provenance timestamps are never left to the LLM's guess at the current time. Chosen over a lighter, POC-bespoke page format because the whole point of adopting OKF here is interoperability with other OKF producers/consumers, which requires actually conforming to the spec rather than taking inspiration from it. The cost is real: every Ingest/Filing prompt must teach the LLM the frontmatter contract, and the log format is now more fiddly to generate than a plain append. `generated` intentionally omits `verified`, `stale_after`, and the `Attested Computation` machinery (§10) — none of the POC's toy content needs them, and OKF requires only `type` for conformance, so the bundle stays valid without them.
